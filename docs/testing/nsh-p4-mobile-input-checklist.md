# CardMind NSH 编辑器 — Android/iOS 真机输入验证清单（待真机）

> 状态：**待真机执行**。本清单为 AC5 交付物。本机（macOS）无 Android/iOS
> 真机/模拟器实机验证。目标：<960 布局下软键盘、选区手柄、长按菜单可用。

## 前置

- Android：设备或模拟器（API 30+），`nsh test --target android` 或安装包。
- iOS：设备或模拟器（iOS 16+），`nsh test --target ios`。
- CardMind 进入「笔记」列表 → 任一笔记编辑器（<960 移动布局：搜索 + 标签 + 列表 + 双 Tab）。

## A. 软键盘

| # | 步骤 | 预期 |
|---|------|------|
| A1 | 点编辑器正文区 | 软键盘弹起，编辑器获得焦点，光标可见 |
| A2 | 输入一段文字（含中英文） | 逐字上屏，无丢字/重复 |
| A3 | 用系统返回手势/键盘收起键 | 键盘收起，编辑器不失焦错乱；内容保留 |
| A4 | 键盘弹起时滚动编辑器 | 内容可滚到被键盘遮挡处；光标不被永久遮挡 |
| A5 | 从编辑器切换到列表再返回 | 键盘状态合理（编辑器重新聚焦或按平台惯例） |

## B. 选区与手柄

| # | 步骤 | 预期 |
|---|------|------|
| B1 | 长按一个词 | 选中该词，出现选择手柄 + 系统选择菜单 |
| B2 | 拖动手柄扩大/缩小选区 | 选区连续变化，边界清晰 |
| B3 | 选中文本后点「复制/剪切」 | 内容进入系统剪贴板；剪切后选区文本删除 |
| B4 | 选中文本后输入新字符 | 替换选区内容，光标落在替换后位置 |
| B5 | 双击/三击（若平台支持） | 按平台惯例选词/段 |

## C. 长按菜单

| # | 步骤 | 预期 |
|---|------|------|
| C1 | 长按文本空白处 | 弹出系统上下文菜单（粘贴/全选等，依平台） |
| C2 | 菜单选「粘贴」（剪贴板有内容） | 粘贴到光标处 |
| C3 | 菜单选「全选」 | 全文选中，出现选区手柄 |
| C4 | 点编辑器外/返回 | 菜单关闭，不误触发返回上级 |

## D. <960 布局可用性

| # | 步骤 | 预期 |
