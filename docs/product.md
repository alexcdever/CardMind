# 产品定义

> 面向唯一用户的个人工具。上次更新：2026-08-12

---

## 一句话

一个跨平台（Android / Windows / macOS）的分布式个人知识库。以 Markdown 笔记为基础，通过双向链接将孤立的笔记编织成知识网络。

---

## 痛点

- 内置备忘录不纯粹：打开看到思维导图推荐、云服务警告
- Markdown 中英文半角符号不兼容，写不了完整语法
- 没有标签系统，回头找笔记困难
- 笔记之间没有关联，积累成堆后无法形成知识网络

---

## 不做什么

- 不做多人协同编辑（单人使用，多设备间 P2P 同步）
- 不做平台化扩张

---

## 交互原则

以微信聊天框为审美基准：输入流畅、无多余按钮、写完即走。

核心交互：
1. 打开编辑器 → 焦点自动落编辑区，不用多点一下
2. 首行即为标题，编辑器内无独立标题字段
3. 关闭页面 → 自动保存，无弹窗确认
4. 输入 `[[` → 弹出标题搜索补全，选中即创建双向链接

---

## 核心能力

| 优先级 | 能力 | 说明 |
|--------|------|------|
| P0 | 双向链接 | 正文写 `[[note-id|别名]]` 创建链接，反向链接面板查看"谁链到了我" |
| P1 | 全文搜索 | 搜索正文、标题、标签文本，展示上下文 |
| P2 | 标签管理 | 独立标签浏览页，标签云，按标签筛选 |
| P3 | 知识图谱可视化 | 力导向图展示笔记之间的链接关系 |

---

## 当前阶段

二期 MVP：在现有笔记编辑器 + 列表的基础上，加入双向链接能力。

| 用途 | 方案 |
|------|------|
| 编辑器 | appflowy_editor（WYSIWYG，原生 Markdown 支持） |
| 本地存储 | Rust 端 Loro CRDT + SQLite 读投影 |
| 多设备同步 | iroh P2P（跨网段 relay 打洞）+ mDNS 设备发现，自动后台同步 |
| 跨平台框架 | Flutter + Rust (flutter_rust_bridge) |
| 链接系统 | 正文解析 `[[...]]` → SQLite links 表，反链查询 |
| 全文搜索 | SQLite FTS5 |

详见 `CONTEXT.md`（领域术语）、`docs/sync-network.md`（同步网络设计）、`docs/adr/`（架构决策记录）。
